# EXECUTION PLAN

## 목표
홀로그램 명함 아이디어를
**샘플 검증 가능한 실물 제품 + 주문형 디지털 configurator MVP** 수준까지 빠르게 끌어올린다.

## 실행 원칙
- 처음부터 복잡한 제조망보다 **소량 샘플 검증 우선**
- 모든 단계에서 **촬영 결과물**이 나오게 설계
- AI는 단순 자동화가 아니라 **개인화 설계 엔진** 역할로 사용

## Phase 1. 물성 검증 (1주)
### 할 일
1. 후가공 방식 shortlist 작성
   - foil stamping
   - hologram laminate
   - spot UV 혼합안
2. 국내 소량 제작처 기준으로 확인할 항목 정리
   - 최소 수량(MOQ)
   - 장당 단가
   - 샘플 가능 여부
   - 리드타임
   - 데이터 입고 방식
3. 샘플용 디자인 2~3종 제작
   - premium minimal
   - flashy collectible
   - hidden reveal

### 산출물
- 제작 방식 비교표
- 샘플 디자인 세트
- 1차 발주안

## Phase 2. 샘플 발주 + 촬영 검증 (1~2주)
### 할 일
1. 가장 유망한 1~2개 가공 방식으로 샘플 발주
2. 수령 후 아래 포인트 촬영
   - 정면 정지샷
   - 각도 변화 숏폼
   - 언박싱 컷
3. 실제로 어떤 패턴이 카메라에서 잘 잡히는지 비교

### 판단 기준
- 영상에서 반짝임이 잘 보이는가
- 싸 보이지 않고 프리미엄으로 보이는가
- 개인화 옵션을 얹기 쉬운가

### 산출물
- 샘플 리뷰 노트
- 촬영 가능한 hero sample 선정
- 최종 가공 방식 1안

## Phase 3. 디지털 configurator MVP 정의 (1주)
### 사용자 입력
- 이름
- 직함
- 브랜드/업종
- 키워드 3개
- 톤 선택
- 반짝임 강도 선택

### 시스템 출력
- 카드 카피 1안
- 레이아웃 시안 1~3안
- 홀로그램 적용 추천 영역
- 샘플 mockup preview

### MVP 범위
- 웹 폼 입력
- AI copy + style recommendation
- 고정 템플릿 기반 preview 생성
- 주문 문의 또는 예약 결제 CTA

## Phase 4. 판매/전환 검증 (1주)
### 테스트 방식
1. 랜딩 페이지 1장 오픈
2. 샘플 영상 업로드
3. 3개 패키지 제안
   - Lite: foil point only
   - Signature: foil + custom tagline
   - Showpiece: advanced pattern + hidden reveal
4. 문의/예약주문/샘플 신청 반응 측정

### 핵심 지표
- 랜딩 체류
- 샘플 영상 클릭률
- 문의 전환율
- 실제 주문 의향
- 선호 스타일 분포

## 추천 역할 분리
### 디자인/브랜드
- 템플릿 스타일 정의
- 샘플 아트워크 제작

### 제작/오퍼레이션
- 인쇄소 커뮤니케이션
- 후가공 샘플 발주
- 단가표 정리

### 제품/개발
- 입력 폼
- AI 카피 생성
- mockup preview 렌더링
- 주문 플로우 연결

## 빠른 의사결정 포인트
대표님이 먼저 결정하면 좋은 것은 3가지입니다.
1. 첫 타깃을 **창업자/크리에이터용**으로 갈지
2. 첫 인상을 **럭셔리**로 갈지 **수집욕형**으로 갈지
3. MVP를 **문의형**으로 열지 **선결제형**으로 열지

## 현재 추천
- 첫 샘플 무드: **럭셔리 70 / 수집욕 30**
- 첫 가공 검토: **foil stamping 우선**
- 첫 MVP CTA: **문의형 또는 예약주문형**

## 한 줄 마무리

**“손에 쥐는 순간 바로 찍고 싶어지는가”** 입니다.

그래서 실행도 그 기준으로 가야 합니다:

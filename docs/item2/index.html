3. Step-by-step quickstart

1
Horn 분리
처음엔 servo horn을 빼고 방향만 확인합니다.
2
ESP32-C3를 Mac에 연결
USB 충전 케이블이 아닌 data cable을 사용합니다.
3
GND 공통 + signal GPIO4
SG90 GND, 외부 5V -, ESP32-C3 GND를 묶습니다.
4
외부 5V ON
SG90 Red는 외부 5V +로만 공급합니다.
5
Firmware upload
Arduino IDE에서 ESP32C3 Dev Module + ESP32Servo library.
6
Serial Monitor 115200
DONE 입력 → 한 번 click 확인.
7
Horn 장착
rest angle에서 key/plunger를 누르지 않게 끼웁니다.
8
각도 조정
PRESS_ANGLE을 2–5°씩 조정해 최소 클릭 각도를 찾습니다.

4. Mac 설치/업로드

Arduino IDE

  1. Arduino IDE 2.x 설치
  2. Settings → Additional boards URL 추가:
    https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json
  3. Boards Manager에서 esp32 by Espressif Systems 설치
  4. Library Manager에서 ESP32Servo 설치
  5. Board: ESP32C3 Dev Module, USB CDC On Boot: Enabled
  6. sg90_clicker_mock.ino Upload

PlatformIO

cd item-2-reactive-keyboard-goods
pio run -e esp32c3-supermini
pio run -e esp32c3-supermini -t upload
pio device monitor -b 115200

5. Firmware 테스트

Serial Monitor에서 아래 명령을 보냅니다.

명령동작
DONE 또는 CLICK즉시 한 번 click
RESTrest angle로 이동
PRESSpress angle로 이동 후 유지
HELP명령 목록 출력
기본 firmware는 6초마다 자동 mock click도 실행합니다. 실제 inference 완료만 받고 싶으면 MOCK_INTERVAL_MS = 0으로 바꿉니다.

7. Troubleshooting

증상확인
Servo 무동작외부 5V, 공통 GND, GPIO4 signal 확인

Upload 실패BOOT 버튼, data cable, port 재선택

키가 안 눌림horn 위치와 PRESS_ANGLE 2–5° 조정

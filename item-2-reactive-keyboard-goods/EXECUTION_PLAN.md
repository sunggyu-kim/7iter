# EXECUTION PLAN

## 목표
item 2를 "설명만 있는 아이디어"에서 **대표님이 바로 고를 수 있는 시연형 후보**로 끌어올린다.

## 추천 MVP 정의
**AI 완료 신호를 받으면 3~6키 매크로패드가 빛으로 반응하는 데모 오브젝트**

- 입력: mock inference complete signal 또는 실제 LLM 완료 이벤트
- 출력: LED 애니메이션
- 선택 출력: 1개 키 또는 토큰의 간단한 기계 반응

## 왜 이 범위가 맞는가
- 풀 키보드보다 훨씬 빨리 만들 수 있음
- 촬영 임팩트는 충분히 강함
- 3D 프린팅 + 시판 전자부품으로 시제품 구성이 가능함
- 이후 굿즈 확장이 자연스러움

## 3단계 실행

### Phase 1. Showable Demo (가장 중요)
기간: 1~2주

목표:
- "완료되면 반응한다"를 눈으로 증명

산출물:
- 3~6키 매크로패드 하우징
- LED 반응 펌웨어
- PC에서 완료 신호를 보내는 간단한 데모 앱/스크립트
- 10~20초 시연 영상

구성:
- MCU: ESP32 또는 Arduino 계열
- 광원: addressable RGB LED
- 하우징: 3D printed shell
- 연결: USB-C 또는 USB 직결

성공 기준:
- 모니터 속 생성 UI와 오브젝트 반응이 안정적으로 동기화됨
- 영상으로 보았을 때 한 번에 이해됨

### Phase 2. Physical Delight Upgrade
기간: 1주 추가

목표:
- "빛나는 장치"를 "만지고 싶은 굿즈"로 승격

산출물:
- 중앙 키 팝업 또는 작은 배지 상승 메커니즘
- 자석/스프링 기반 간단한 기구 실험
- 소리/진동 여부 테스트

성공 기준:
- 기계 반응이 과하지 않고, 짧고 귀엽게 마무리됨

### Phase 3. Brandable Productization
기간: 1~2주 추가

목표:
- 전시/판매/협업 가능한 제품 콘셉트로 정리

산출물:
- 컬러웨이 2~3종
- 로고/각인 버전
- 패키지 및 데스크 연출안
- 행사 부스용 데모 시나리오

## 핵심 의사결정 포인트
### 1. 반응 방식 우선순위
1순위: LED
2순위: 1개 포인트 기계반응
3순위: 복잡한 전체 기구

**판단**: 처음부터 움직임에 욕심내기보다 LED 완성도를 높이는 편이 안전합니다.

### 2. 제품 형태 우선순위
1순위: 매크로패드형
2순위: 데스크토이형
3순위: 풀 키보드형

### 3. 신호 연동 방식
- 데모용: 로컬 앱 또는 스크립트로 완료 이벤트 송신
- 확장형: 실제 LLM 응답 완료 훅과 연결

## 리스크와 대응
### 리스크 A. 하드웨어 난이도 상승

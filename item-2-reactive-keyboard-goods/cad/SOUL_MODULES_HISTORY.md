# SG90 SOUL Modules v0.1

Date: 2026-05-08

## Context
Item 2 currently uses the SG90 Hardware Capsule v0.2. The capsule hides the ESP32-C3 SuperMini, wiring, and SG90 body while exposing only the USB-C slot and the top servo drive window.

The current CAD intentionally omitted the Soul object and left a top interface socket for future interchangeable interactive items.

## Goal
Design lightweight SG90 horn-compatible SOUL modules that can be swapped on top of the existing capsule without changing the base electronics or cover.

## Shared Interface
- Compatible with the existing top socket ring.
- Clears SG90 horn movement.
- Provides central screw access for SG90 horn fastening.
- Keeps mass low to avoid SG90 buzzing, overheating, or missed clicks.
- Printable as simple decorative modules.

## Initial SOUL Set

## Design Rule
The hardware capsule remains generic. Personality lives only in the removable SOUL module.

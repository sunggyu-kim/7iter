# BRIEF

## 아이템명
추론 완료 반응형 키보드 / 굿즈

## 한 줄 설명
AI 추론이 끝나는 순간 색, 빛, 기계적 움직임 중 하나로 반응하는 물성형 데모 제품.

## 왜 중요한가
- 추론 완료라는 보이지 않는 과정을 **눈에 보이는 콘텐츠**로 바꿔줌
- 사용 장면 자체가 쇼츠/릴스/전시 데모가 됨
- 키보드, 데스크토이, 버튼형 굿즈 등으로 확장 가능

## 현재 단계
- iteration 7 브리프 수준의 아이디어 정의 완료
- 전용 SW화 세션은 아직 없음
- 3D printing 기반 프로토타입 제작 트랙 후보

## 우선 검토 포인트
1. 반응 방식: LED / 모터 / 팝업 메커니즘 / 색변화 소재
2. 입력 신호: 실제 inference 완료 이벤트 vs 데모용 mock signal
3. 제작 방식: 3D printing 가능한 하우징 + 시판 부품 조합
4. 결과물 형태: 키보드 전체 / 키캡 모듈 / 작은 데스크 굿즈

## 다음 단계 제안
- 기구 컨셉 스케치
- BOM 초안
- 3D print 시제품 난이도와 부품 조달성 검토
- MVP를 ‘완료 신호를 보여주는 작은 오브젝트’로 축소할지 검토

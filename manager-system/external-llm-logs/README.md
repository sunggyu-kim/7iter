# External LLM / Local Tool Logs

This folder records work done outside the current manager-controlled OpenClaw run.

Do not create one markdown file per LLM. Instead, append log entries by date.

Examples of environments/tools to log:
- local Codex
- another OpenClaw run
- Gemini
- Claude
- OpenAI
- Grok
- Blender / 3D tool
- manual local edit

Each entry should include item, source environment, request summary, files touched, validation, manager decision, and GitHub sync target.

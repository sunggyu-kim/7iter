# PRODUCT_PLAN

## 1. Product concept
**Working name:** Mosaic Year

Mosaic Year turns a person's photo archive from the last 12 months into a single large hero image composed of their own smaller photos. The result works in two modes:
- **Poster mode:** one beautiful shareable final image
- **Explorer mode:** zoom into the mosaic and inspect the tiny source photos

This is not just a collage. The core magic is that hundreds or thousands of personal moments reconstruct a meaningful target image.

## 2. User value
- Converts messy personal photo history into a polished keepsake
- Creates an emotionally strong “look back at my year” artifact
- Feels highly personal because every result is built from the user's own images
- Produces an easy-to-share visual for Instagram, Reels, Stories, gifting, or printing

## 3. Instagrammable hook
The hook is the **reveal contrast**:
1. User sees one clean, striking hero image from afar
2. User pinches/zooms in
3. The hero image breaks into hundreds of their own life moments

This supports strong social content:
- “This entire portrait is made from my 2025 photos”
- before/after reveal video
- zoom screen recording for Stories/Reels
- printed poster + digital version bundle

## 4. Personalization logic
Each user should get a meaningfully different result through a few layers:

### A. Source uniqueness
- Use only that user's uploaded images
- Optional filter by date range (e.g. last 12 months)

### B. Target-image choice
User selects one of:
- Self portrait / couple portrait / family portrait
- Pet image
- Travel memory image
- Template artwork (heart, year number, skyline, etc.)

### C. Auto styling
System derives style from the dataset:
- dominant color mood
- dense vs airy tile layout
- square vs rounded tile crop style
- optional month-based region grouping

### D. Story overlays (optional premium)
- month labels on hover
- “top moments” highlights
- printed caption or year stamp

## 5. Core product format
### Free demo
- Upload limited number of photos
- Generate watermarked low-res mosaic preview
- Interactive zoom viewer
- Limited export/share

### Paid product
- Full-resolution downloadable image
- Clean export without watermark
- Print-ready file
- Optional short zoom-reveal video export

## 6. User journey
### Entry
- User lands on a simple page with a compelling demo
- Promise: “Turn your year of photos into one zoomable mosaic artwork”

### Creation flow
1. Upload 100-1000 photos
2. Pick a target image or upload one
3. Choose style preset
4. Preview generation progress
5. Receive interactive mosaic preview
6. Zoom/explore result
7. Unlock HD export / print version / reveal video

### Post-purchase path
- Download digital asset immediately
- Upsell print/poster option
- Prompt for social sharing with branded hashtag/template

## 7. Monetization / experience path
### Best initial model
**Freemium + paid export**
- Free: watermarked preview + low-res interactive viewer
- Paid basic: HD image export
- Paid plus: HD export + print-ready file + reveal video

### Possible price framing
- Basic digital export: impulse-purchase tier
- Premium keepsake bundle: gift tier

### Expansion options
- Wedding mosaic
- Baby first-year mosaic
- Team/company year-in-review mosaic
- Event booth / instant mosaic generation
- Printed merchandise

## 8. MVP recommendation
For MVP, optimize for one job:
> Help a user upload photos, generate one compelling zoomable mosaic, and pay to unlock a polished export.

Avoid building social feeds, accounts-heavy features, or advanced AI editing too early.

## 9. Success criteria for first demo
- User can upload a photo set without confusion
- Mosaic generation finishes reliably in a reasonable time
- Final result looks good enough to share unprompted
- Zoom reveal feels delightful on mobile
- At least one clean paid unlock moment exists

# MVP_SPEC

## 1. v1 목표
사용자가 간단한 입력만으로 **개인화된 디지털 명함 + 짧은 스토리보드 결과물**을 생성하고, 무료 체험 후 유료 다운로드 또는 고급 옵션 구매로 전환되는 MVP를 만든다.

## 2. 핵심 기능
1. **입력 폼**
   - 이름, 역할, 소개, 키워드, 무드, 목적
   - 사진/로고 선택 업로드 (선택)

2. **AI 카피 생성**
   - 명함 헤드라인
   - 서브카피
   - 컷별 스토리보드 문구

3. **템플릿 렌더링**
   - 디지털 명함 1안 자동 생성
   - 스토리보드 3~4컷 자동 생성
   - 1:1 / 9:16 미리보기 제공

4. **미리보기 + 제한 해금 구조**
   - 무료: 워터마크/저해상도
   - 유료: 고해상도 및 전체 다운로드

5. **공유/전환 기능**
   - 이미지 저장
   - 링크 공유
   - 결제 버튼

## 3. v1 범위에 넣고, 빼야 할 것

### 포함
- 2~3개 스타일 preset
- 텍스트 기반 개인화
- 단일 결과 세트 생성
- Stripe/Toss 등 단순 결제 연동
- 이미지/PDF 다운로드

### 제외
- 실시간 고급 편집기
- 팀 협업
- 인쇄/물류 직접 연동
- 완전 자유형 디자인 툴
- 영상 생성/애니메이션
- 복잡한 SNS 자동 게시

## 4. 단순 아키텍처
- **Frontend**: 입력 폼, 미리보기, 결제 UI
- **Backend API**:
  - 사용자 입력 수신
  - LLM으로 카피/스토리 생성
  - preset 선택 로직 실행
  - 이미지/PDF 렌더링 트리거
- **Storage**:
  - 업로드 이미지
  - 생성 결과물
- **Payments**:
  - 유료 해금 처리

## 5. 추천 스택

### 빠른 MVP용
- **Frontend**: Next.js
- **UI**: Tailwind CSS + shadcn/ui 또는 간단한 컴포넌트 세트
- **Backend**: Next.js API routes / Server Actions
- **LLM**: OpenAI 또는 Gemini로 카피/스토리 생성
- **Rendering**:
  - HTML/CSS 기반 카드 렌더링
  - `@react-pdf/renderer` 또는 서버 스크린샷 방식
- **Storage**: Supabase Storage 또는 S3
- **DB**: Supabase Postgres
- **Auth**: 초기는 익명 세션 또는 magic link
- **Payments**: Stripe 또는 국내 전환 고려 시 Toss Payments

## 6. 화면 구성
1. 랜딩 페이지
2. 생성 폼
3. 결과 미리보기 페이지
4. 결제 모달/체크아웃
5. 다운로드 완료 페이지

## 7. 리스크
- **결과물 품질 편차**: 카피는 괜찮아도 비주얼 만족도가 낮을 수 있음
- **개인화 체감 부족**: 입력 대비 결과가 너무 템플릿 같으면 전환 저하
- **렌더링 복잡도**: 다양한 비율 출력 지원 시 구현 난이도 상승
- **결제 이전 가치 전달 실패**: 무료 미리보기에서 충분한 wow 포인트가 필요

## 8. 리스크 대응
- 템플릿 수를 줄이고 완성도 높은 preset부터 시작
- 프롬프트보다 출력 레이아웃 품질에 더 투자
- 무료 단계에서도 공유하고 싶을 정도의 카드 1장을 확실히 제공
- 생성 시간을 10~20초 내로 유지

## 9. 데모 우선순위
가장 먼저 보여줄 데모는:
- 5개 입력
- 10초 내 결과 생성
- 명함 카드 + 3컷 스토리보드 출력
- 워터마크 제거 결제 CTA

이 흐름이 작동하면 판매/피드백/광고 테스트까지 바로 가능하다.

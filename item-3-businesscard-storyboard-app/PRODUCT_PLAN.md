# PRODUCT_PLAN

## 1. 제품 한 줄 정의
사용자가 몇 가지 정보만 입력하면 **개인화된 디지털 명함 + 3~6컷 스토리보드**를 즉시 생성하고, 이를 공유/다운로드/주문 전환까지 연결하는 AI 콘텐츠 앱.

## 2. 핵심 사용자 가치
- **빠른 자기표현**: 나를 소개하는 명함을 평범한 텍스트가 아니라 스토리로 보여줌
- **즉시 체험 가능**: 가입 없이 샘플 생성까지 빠르게 진입 가능
- **공유 유도**: 인스타 스토리/릴스/피드에 올리기 좋은 시각 결과물 제공
- **구매 전환성**: 디지털 결과물을 실물 명함, PDF 키트, 브랜드 패키지 구매로 연결 가능

## 3. 타깃 사용자
1. 1인 창업가 / 프리랜서
2. 취준생 / 대학생 / 크리에이터
3. 행사/네트워킹 참가자
4. 작은 브랜드/로컬숍 운영자

## 4. 인스타그래머블 훅
- 입력 1분 → 결과 30초 내 생성
- 결과물은 아래 2개가 한 번에 나옴:
  - **AI 비주얼 명함**: 프로필, 한 줄 포지셔닝, 컬러/무드 반영
  - **미니 스토리보드**: “나는 누구인가 / 무엇을 하는가 / 왜 기억해야 하는가”를 컷 단위로 표현
- 공유용 출력:
  - 9:16 스토리 카드
  - 1:1 피드 카드
  - 저장용 PDF/PNG

## 5. 개인화 로직

### 입력값
- 이름 / 활동명
- 직업 또는 역할
- 한 줄 소개
- 키워드 3개
- 선호 무드 (예: 미니멀, 럭셔리, 위트, 테크)
- 사용 목적 (네트워킹, 포트폴리오, 브랜드 홍보, 채용)
- 선택 입력: 사진/로고, SNS/링크

### 생성 로직
- **명함 카피**: 역할 + 차별점 + 톤을 반영해 헤드라인/서브카피 생성
- **비주얼 스타일**: 무드와 키워드 기반으로 컬러/타이포/레이아웃 preset 매칭
- **스토리보드 서사**:
  - 컷 1: 나의 정체성
  - 컷 2: 내가 하는 일
  - 컷 3: 문제 해결/강점
  - 컷 4: 협업 또는 연락 유도
  - 필요 시 컷 5~6: 브랜드 세계관/사례
- **CTA 개인화**:
  - 취준생 → 포트폴리오 보기
  - 창업가 → 상담 문의
  - 크리에이터 → 협업 DM 유도
  - 행사 참가자 → 연락처 저장/QR 스캔

## 6. 사용자 여정

### A. 체험형 퍼널
1. 랜딩: “30초 만에 내 명함+스토리보드 만들기”
2. 빠른 입력 폼 작성
3. 무료 미리보기 생성
4. 결과 일부 공개:
   - 명함 1안
   - 스토리보드 3컷 미리보기
5. 업셀 제안:
   - 전체 컷 열기
   - 고해상도 다운로드
   - QR 포함 디지털 명함 저장

### B. 구매형 퍼널
1. 무료 체험 후 만족
2. 유료 플랜 선택
3. 결과물 커스터마이즈
4. 결제
5. 다운로드 또는 실물 제작 주문 연결

## 7. 수익화 / 경험 경로

### 무료
- 워터마크 포함 미리보기
- 제한된 템플릿 1~2종
- 저해상도 공유 이미지

### 유료 단건
- 고해상도 PNG/PDF
- 워터마크 제거
- 템플릿 선택 확대
- QR 코드 / 링크 카드 포함

### 유료 프리미엄
- 스토리보드 확장본 (5~6컷)
- 다국어 버전
- 브랜드 컬러 반영
- 실물 명함 인쇄용 파일 제공

### B2B/행사용 옵션
- 행사 참가자용 대량 생성
- 팀 명함 통일 템플릿
- 브랜드/학교/커뮤니티 전용 스킨

## 8. MVP에서 꼭 보여줘야 할 것
- “입력 → 생성 → 공유/결제”가 한 세션 안에서 닫힐 것
- 결과물이 생각보다 예쁘고, 개인화가 느껴질 것
- 무료 체험과 유료 해금 차이가 분명할 것

## 9. 추천 포지셔닝
“명함 제작 툴”보다 **‘나를 소개하는 AI 스토리 명함’**으로 포지셔닝하는 편이 차별화에 유리함.

## 10. 초기 성공 지표
- 랜딩 → 생성 완료율
- 생성 완료 → 공유율
- 생성 완료 → 결제 전환율
- 유저당 평균 재생성 횟수
- 결과물 저장/다운로드율

# Item 3-1 Jellyfish Web Asset Spec

## Constraint
No external image, no downloaded asset, no copied reference. Use only original inline SVG/CSS/HTML.

## Layers
1. Bell shell — translucent dome path with radial cyan/violet glass gradient.
2. Rim glow — lower rim stroke with blur and opacity variation.
3. Inner volume — soft abstract organs/blobs inside dome.
4. Caustics — thin curved white/cyan strokes, screen blend.
5. Oral arms — thicker center ribbons.
6. Tentacles — 8~12 Bezier paths with varied length and delayed sway.
7. Bubbles/particles — small circles with slow vertical drift.

## Motion
- Bell breathing: subtle 3~5% scale pulse.
- Tentacles: alternating sway, different delays.
- Pointer parallax: object rotates separately from card.
- Reduced motion: static object, no continuous animation.

## Acceptance
The object should feel like a small transparent 3D collectible embedded in a glass business card, not a flat icon.

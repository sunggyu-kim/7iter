# VISUAL CONCEPT

## 콘셉트 한 줄
**“한 사람의 명함이 아니라, 한 사람의 세계관을 카드처럼 펼친다.”**

## 원하는 첫인상
- 3초 안에 “평범한 명함 앱이 아니다”가 느껴져야 함
- 결과물이 캡처만 해도 공유하고 싶어야 함
- AI 냄새보다 **브랜드 결과물**처럼 보여야 함

## 핵심 비주얼 방향
### 1. Hero object: AI Story Card
- 메인 산출물은 단순 텍스트 명함이 아니라 **비주얼 카드**
- 카드 1장만 봐도 직업/무드/차별점이 읽혀야 함
- 연락 정보는 보조, 포지셔닝 문구는 전면 배치

### 2. Storyboard reveal
- 결과 페이지에서 카드 아래로 3~6컷 스토리보드가 이어짐
- 사용자는 ‘명함을 받는 경험’이 아니라 ‘한 사람을 짧게 소개받는 경험’을 하게 됨
- 세로 스크롤 캡처만으로 SNS 공유가 가능해야 함

### 3. Mobile-first shareability
- 최우선 출력 비율은 **9:16**
- 그 다음이 **1:1**
- 웹 화면 자체가 인스타 스토리/릴스 커버처럼 보여야 함

## 디자인 원칙
1. **텍스트는 짧고 강하게**
   - 헤드라인 1줄
   - 서브카피 1~2줄
   - 컷별 메시지 1문장
2. **템플릿 수보다 완성도 우선**
   - 초기는 3개 스타일만
3. **AI 생성물 같지 않게**
   - 과도한 장식보다 정돈된 브랜딩 톤
4. **캡처했을 때 예뻐야 함**
   - 앱 안에서보다 스크린샷 상태를 기준으로 검토

## MVP 템플릿 3종 제안
### A. Minimal Founder
- 대상: 창업가, 프리랜서, 컨설턴트
- 키워드: clean, premium, confident
- 컬러: ivory / black / cobalt
- 타이포: 굵은 산세리프 + 얇은 보조 텍스트
- 특징: 짧은 선언형 헤드라인, 정제된 레이아웃

### B. Creator Moodboard
- 대상: 크리에이터, 디자이너, 마케터
- 키워드: expressive, trendy, visual
- 컬러: off-white / tomato / deep navy
- 특징: 컷마다 강조 색이 달라지고, 무드보드 같은 리듬감

### C. Career Spotlight
- 대상: 취준생, 대학생, 주니어 직군
- 키워드: sharp, optimistic, credible
- 컬러: white / graphite / electric blue
- 특징: 강점과 잠재력을 또렷하게 보여주는 자기소개형 구성

## 결과물 구조
### 카드 1장
- 이름 / 활동명
- 역할
- 한 줄 포지셔닝
- QR 또는 링크 CTA

### 스토리보드 3~6컷
1. 나는 누구인가
2. 무엇을 하는가
3. 어떤 강점이 있는가
4. 왜 연락해야 하는가
5. 대표 사례 또는 철학 (옵션)
6. CTA (옵션)

## 모션/연출 가이드
- 입력 완료 후 10~20초 내 생성
- 결과 등장 시 카드 → 컷 1 → 컷 2 → 컷 3 순서로 reveal
- 과한 애니메이션보다 **차분한 등장감**이 중요
- 광고용 데모에서는 typing, loading, reveal 3단 리듬을 활용

## 랜딩 비주얼 메시지
- 카피: **“내 소개를, 기억에 남는 카드로.”**
- 서브카피: **“30초 입력으로 명함과 스토리보드를 동시에 생성.”**
- 첫 화면에는 입력폼보다 결과 예시를 먼저 보여주는 편이 유리함

## 절대 피할 것
- 흔한 AI 아바타 생성기처럼 보이는 비주얼
- 템플릿 마켓 느낌의 산만한 썸네일 구성
- 너무 많은 편집 옵션
- 명함 정보가 작고 CTA가 묻히는 레이아웃

## 실무 체크포인트
- 모든 템플릿은 9:16, 1:1에서 둘 다 무너지지 않아야 함
- 저해상도 무료본도 예뻐야 공유가 일어남
- 텍스트 길이가 길어져도 레이아웃이 깨지지 않아야 함
- 실제 타깃 3명만 넣어봐도 서로 다른 결과처럼 보여야 함

## 결론
비주얼 방향은 **‘AI 생성물’보다 ‘짧은 자기 브랜딩 캠페인 결과물’**에 가깝게 가야 합니다.

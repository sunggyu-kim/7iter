# EXECUTION PLAN

## 목표
4주 안에 **광고 가능한 MVP**를 만들어, 실제 생성률/공유율/결제전환을 검증한다.

## 최종 산출물
- 랜딩 페이지 1종
- 입력 폼 1종
- 결과 템플릿 3종
- 명함 1장 + 스토리보드 3~4컷 생성 플로우
- 워터마크 무료본 / 유료 해금본
- PNG/PDF 다운로드
- 결제 CTA

## 4주 실행안

### Week 1 — 제품/브랜드 확정
**목표:** 팔리는 메시지와 결과물 기준선 정의
- 타깃 세그먼트 3개 확정: 창업가 / 크리에이터 / 취준생
- 템플릿 3종 비주얼 시안 확정
- 입력값/출력 구조 확정
- 카피 프롬프트 초안 작성
- 랜딩 핵심 카피 확정

**완료 기준**
- “이 결과면 돈 낼 수 있다” 수준의 정적 시안 3세트 확보

### Week 2 — 생성 MVP 구현
**목표:** 입력 → 생성 → 결과 보기까지 연결
- 폼 UI 구현
- LLM 카피 생성 연결
- preset 선택 로직 구현
- 결과 페이지 렌더링
- 무료 워터마크 버전 출력

**완료 기준**
- 더미가 아닌 실제 입력으로 10~20초 내 결과 생성

### Week 3 — 수익화/다운로드 구현
**목표:** 체험에서 결제까지 닫기
- 결제 링크 또는 체크아웃 연동
- 유료 해금 로직 구현
- PNG/PDF export 구현
- QR 링크 포함 옵션 정리
- 분석 이벤트 삽입

**완료 기준**
- 내부 테스트에서 결제 후 결과 다운로드 가능

### Week 4 — 광고/실험 준비
**목표:** 외부 반응 검증 가능한 상태 만들기
- 샘플 6~9개 제작
- 랜딩 A/B 카피 2안 준비
- 숏폼 데모 영상 2종 제작
- 테스트 유입 채널 설정
- 초기 가격 실험안 확정

**완료 기준**
- 실제 유입을 태워도 되는 공개 상태 도달

## 권장 팀 배치
### 1. 제품 오너
- 포지셔닝, 우선순위, 결과 품질 기준 결정

### 2. 디자인/브랜드
- 템플릿 3종 설계
- 랜딩/공유 이미지 품질 관리

### 3. 개발
- Next.js 기반 폼/결과/결제 구현
- 렌더링 및 export 처리

### 4. 콘텐츠/그로스
- 광고 크리에이티브 제작
- 샘플 입력 시나리오 설계
- 전환 데이터 해석

## 핵심 지표
- 랜딩 방문 → 생성 시작률
- 생성 시작 → 생성 완료율
- 생성 완료 → 공유율
- 생성 완료 → 결제 클릭률
- 결제 클릭 → 구매 전환율
- 무료 사용자 재방문/재생성률

## 가격 실험 제안
### 안 A: impulse purchase
- 4,900원: 고해상도 해금
- 9,900원: 확장 스토리보드 + PDF

### 안 B: premium branding
- 9,900원: 디지털 명함 패키지
- 19,000원: 인쇄용 파일 + 다국어 + 확장 컷

초기에는 **안 A**가 전환 실험에 유리합니다.

## 주요 리스크와 대응
### 1. 결과물이 밋밋할 위험
- 대응: 템플릿 수를 줄이고, 샘플 결과 품질부터 끌어올리기

### 2. AI 카피가 과장되거나 뻔할 위험
- 대응: 세그먼트별 프롬프트 분기 + 금지 표현 리스트 운영

### 3. 무료만 쓰고 이탈할 위험
- 대응: 무료본은 공유되게 만들되, 다운로드/인쇄 가치는 유료에 집중

### 4. 명함으로 인식되지 않을 위험
- 대응: 모든 결과에 연락/QR/역할 정보는 반드시 유지

## 대표님 의사결정 포인트
### 바로 Go 해도 되는 이유
- 제작 속도가 빠름
- 실험 비용이 낮음
- 콘텐츠 마케팅 소재가 풍부함
- item 4 실물 명함과 연계 가능

### Hold 해야 하는 경우
- 템플릿 완성도를 확보할 디자인 리소스가 전혀 없을 때
- 결제 실험보다 단순 브랜드 쇼케이스가 우선일 때

## 추천 운영 순서
1. 디지털 MVP 공개
2. 반응 좋은 템플릿/문구 파악
3. 실물 명함 옵션 추가
4. 행사/B2B 패키지 확장

## 최종 권고
이 아이템은 **작게 시작해서 빠르게 매출/반응을 동시에 볼 수 있는 실행형 안**입니다.  
대표님이 seven iter에서 “보여주기 좋고, 바로 팔아보기 좋은” 후보를 하나 먼저 고른다면, item 3를 선행 착수하는 전략이 가장 합리적입니다.

UX Flow

A꾸미기 우선

게임 캐릭터 커스터마이징처럼 스타일, 폰트, 스티커, 배경 무드를 먼저 선택합니다. 정보 입력 전에도 “내 카드가 멋있어질 것 같다”는 기대를 만듭니다.

B보안 입력

연락처·SNS·회사 정보는 입력 중 마스킹, 공개/비공개 토글, 발행 전 preview consent sheet를 거칩니다.

CQR/Social Hub

QR 촬영 또는 NFC 태깅 시 Instagram, YouTube, Threads, X, 웹사이트, vCard 저장 버튼이 한 페이지에서 열립니다.

DAirDrop/vCard

iOS Safari에서는 Web Share API + .vcf 다운로드를 우선 사용하고, 네이티브 앱 전환 후 AirDrop contact card를 직접 호출합니다.

ENFC 실물 카드

실물 카드에는 profileId 기반 redirect URL만 기록합니다. 사용자는 앱에서 태깅 후 노출 정보와 링크를 계속 수정할 수 있습니다.
